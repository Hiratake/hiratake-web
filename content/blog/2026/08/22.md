ここ数年の技術進歩が著しい AI。そんな AI が、書いたコードをレビューしてくれる **CodeRabbit というサービスを使ってみました🐇** 私は [Hiratake Web](/) というウェブサイトにて定期的にブログもとい日記を投稿しているのですが、フルタイムで働きながら休日などにバーっと文章を書き殴っており、書いた文章をしっかりと見直しできるほど時間に余裕がないのが実情です。

以前までは [Gemini Code Assist にレビューをしてもらっていた](/blog/20250409/) のですが、今年 2026 年 7 月 17 日をもって無料でのサービス提供が終了してしまいました。Gemini に文章をチェックしてもらうたびに「うわっ…私の文章の誤字・脱字、多すぎ…？」となっており、そんな大量の誤字・脱字を指摘してくれる別のサービスを探していたところ、[CodeRabbit](https://www.coderabbit.ai/ja) というサービスを教えていただいたので、使ってみることにしました。

---

[CodeRabbit](https://www.coderabbit.ai/ja) は、GitHub や GitLab などで作成したプルリクエストで変更したコードを AI がレビューしてくれるというサービス。基本的には有料のサービスではありますが、Public のリポジトリであればレビューを永久に無料で受けられるとのこと。

![CodeRabbitとGitHubを連携する画面の画像](9e87cf52-2348-4bb1-d546-ea145ed09f00)

導入方法は簡単で、CodeRabbit のウェブサイトにて各種プラットフォーム（今回は GitHub）のアカウントを連携し、レビューをしてもらいたいリポジトリを追加するだけ。これで CodeRabbit からのレビューを受ける準備は完了で、リポジトリにプルリクエストを作成すると AI がコードをチェックしてくれるようになります。

ためしに日記の投稿のプルリクエストを作成してみると、ウサギさんのアイコンの bot からコメントが投稿されて、しばらくした後にプルリクエストでの変更内容の概要（今回の場合は「こういう内容の新しいブログ記事を追加しました」みたいな感じのもの）や、文章に対しての指摘などが表示されました。

私の [Hiratake Web のリポジトリ](https://github.com/Hiratake/hiratake-web) は、ありがたいことに Stars の数が 10 を超えているのでプルリクエストを作成すると自動でレビューが実行されましたが、CodeRabbit を紹介してくださった方や [CodeRabbit のドキュメント](https://docs.coderabbit.ai/management/plans) によると Stars が 10 未満の場合は手動で実行しないといけないらしい。~~ふぁぼれよ (´へωへ`*)~~

![GitHubのPRに投稿されたCodeRabbitのコメントの画像](9cf41924-15bb-41d6-57e9-bca4b8c02b00)

設定をいじらなくても十分利用可能ではありますが、レビュー対象のリポジトリに `.coderabbit.yaml` という設定ファイルを追加することで CodeRabbit の動作をカスタマイズすることができます。

```yaml [.coderabbit.yaml]
# https://docs.coderabbit.ai/reference/configuration
language: 'ja-JP'
reviews:
  profile: 'chill'
  request_changes_workflow: false
  high_level_summary_in_walkthrough: true
  collapse_walkthrough: false
  poem: false
  review_status: true
  review_details: false
  auto_review:
    enabled: true
    drafts: false
chat:
  auto_reply: true
```

デフォルトでは言語設定が英語になっているので `language` に `ja-JP` を設定してみたり、プルリクエスト作成時に書いた自分のコメントが編集されて「Summary by CodeRabbit」が挿入されるのがちょっと嫌だったので `high_level_summary_in_walkthrough: true` の設定を追加してみたり、ポエムはいらんかも…と思ったので無効にしてみたりしたところ、ちゃんとそのように動作が変更されました。

![CodeRabbitからのレビューの画像](1dfd188c-5c34-4afa-4ad4-7798559d3b00)

また、CodeRabbit は `AGENTS.md` や `CLAUDE.md`、`.github/copilot-instructions.md` といった他の AI ツール向けのドキュメントを自動的に検出して読み込んでくれるそう。

CodeRabbit を使用する前に利用していた Gemini Code Assist 向けに用意していたドキュメントや、その後使っていた Gemini の Gem のカスタム指示をまとめなおして置いてみましたが…本当にちゃんと参照してくれているのかはちょっと謎。書いた日本語の文章に対して、それっぽい指摘をしてくれているのでちゃんと見てくれているのだとは思う…たぶん。

---

AI がコードをレビューしてくれる CodeRabbit を使ってみましたが、無料で利用できるというのが個人でいろいろやっている人間にとってはかなり助かるなと感じました。プルリクエストへのコメントにアスキーアートのようなものを挟んでくるなど、遊び心があるのもグッドです。

レビューの精度については、今回見てもらっていたのがブログもとい日記の記事だったため、若干指摘内容が微妙なことが多いなという印象。プログラムのコードを見てもらう分にはちゃんとした指摘をしてくれそうです。

サービスを提供するためにかなりのコストがかかっているはずなので、今後徐々に無料版は制限されていくのだろうとは思いますが、それまで活用させていただこうと思います。
