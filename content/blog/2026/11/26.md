[pnpm](https://pnpm.io/) を使用しているプロジェクトで、[GitHub Actions](https://github.com/features/actions?locale=ja) を用いてエラーのチェックや ESLint などのツールでの構文チェック、TypeScript の型チェックなどを行っているのですが、これまでの **`pnpm/action-setup` というアクションとは別の `pnpm/setup` というアクションがリリースされていた** ので、置き換えてみました。

今後は [`pnpm/action-setup`](https://github.com/pnpm/action-setup) ではなく [`pnpm/setup`](https://github.com/pnpm/setup) の方を使っていくことになるだろうというのと、まだ以前からのアクションを使用しているプロジェクトもあるので、移行時に行った作業について備忘録的な感じで書いておこうと思います。

## これまでのワークフロー

これまで使用していた `pnpm/action-setup` でのワークフローは、ざっくり以下のような流れでした。

1. `actions/checkout` でリポジトリの内容を取ってくる
2. `pnpm/action-setup` でワークフローの実行環境上に pnpm をセットアップする
3. `actions/setup-node` でワークフローの実行環境上に Node.js をセットアップする
4. `pnpm install` コマンドを実行してパッケージをインストールする
5. ESLint や型チェック、ビルドなどのコマンドを実行する

たとえば、新しいコミットがプッシュされた時に ESLint で構文チェックを行う場合には以下のような YAML ファイルを `.github/workflows/` に `ci.yaml` のような名前で作成していました。

```yaml [.github/workflows/ci.yaml]
name: CI

on:
  push:

permissions: {}

jobs:
  # Lint
  lint:
    name: Lint
    runs-on: ${{ matrix.os }}
    strategy:
      matrix:
        os: [ubuntu-latest]
        node: [24]
    timeout-minutes: 10
    steps:
      - name: Checkout
        uses: actions/checkout@v7
      - name: Setup pnpm
        uses: pnpm/action-setup@v6
      - name: Setup Node.js
        uses: actions/setup-node@v7
        with:
          node-version: ${{ matrix.node }}
          cache: 'pnpm'
      - name: Install dependencies
        run: pnpm install
      - name: Run lint
        run: pnpm lint
```

## `pnpm/setup` へ移行する

移行先となる `pnpm/setup` では、これまでのワークフローの「2. `pnpm/action-setup` でワークフローの実行環境上に pnpm をセットアップする」「3. `actions/setup-node` でワークフローの実行環境上に Node.js をセットアップする」「4. `pnpm install` コマンドを実行してパッケージをインストールする」を 1 つのアクションにまとめることが可能。

- [pnpm/setup: Install pnpm and a JavaScript runtime (Node.js, Bun, or Deno) in one GitHub actions step](https://github.com/pnpm/setup)

こちらのアクションを使用するには pnpm v11 以降が必要で、v10 以前を使っている場合は引き続き以前のアクションを使うことになるようです。

先ほど例として出したワークフローを `pnpm/setup` に変更した場合は以下のようになります。

```yaml [.github/workflows/ci.yaml]
name: CI

on:
  push:

permissions: {}

jobs:
  # Lint
  lint:
    name: Lint
    runs-on: ${{ matrix.os }}
    strategy:
      matrix:
        os: [ubuntu-latest]
        node: [24]
    timeout-minutes: 10
    steps:
      - name: Checkout
        uses: actions/checkout@v7
      # - name: Setup pnpm
      #   uses: pnpm/action-setup@v6
      # - name: Setup Node.js
      #   uses: actions/setup-node@v7
      #   with:
      #     node-version: ${{ matrix.node }}
      #   cache: 'pnpm'
      # - name: Install dependencies
      #   run: pnpm install
      - name: Setup pnpm
        uses: pnpm/setup@v3
        with:
          runtime: node@${{ matrix.node }}
          cache: true
      - name: Run lint
        run: pnpm lint
```

これまで `actions/setup-node` で指定していた Node.js のバージョンやキャッシュの設定も `pnpm/setup` に `runtime: node@${{ matrix.node }}` や `cache: true` を渡すことで対応できます。使用する pnpm のバージョンは、これまで通り `package.json` の `packageManager` が参照されます。

ワークフローのファイルが短くなるのでメンテナンスもしやすくなりますし、私はワークフローでアクションを使用するときにはコミットハッシュを指定して使うバージョンを固定しているのですが、1 つになることでバージョン更新時の手間も少し削減されます。
